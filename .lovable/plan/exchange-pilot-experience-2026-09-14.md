# EXCHANGE pilot experience

## Product interpretation
EXCHANGE will be presented as a campus trust network, not a catalogue of classes. Teaching creates credits, learning spends them, and completed exchanges strengthen a portable Skill Passport. The first experience should make all three loops—exchange, trust, and reputation—visible at once.

## What will be built
- Replace the blank home screen with the selected **Clay Passport Command** workspace.
- Create a polished Universitas Indonesia pilot dashboard centered on one student’s active exchange life.
- Give equal weight to learning opportunities and teaching offers, using credits rather than prices.
- Make the Skill Passport a primary identity surface with verified skills, progress, badges, and peer reputation.
- Surface trust through student verification, session ratings, mutual connections, and verified exchange history.
- Add practical interactions for switching between learning and teaching, requesting a seat, navigating workspace sections, and viewing notifications.
- Adapt the full experience for desktop, tablet, and mobile while preserving the selected composition and hierarchy.

## Visual direction
- Warm paper and off-white surfaces with deep campus green, mint, butter, clay, and rose accents.
- Space Grotesk for product identity and headings; Inter for clear, compact workspace text.
- Mature editorial density, restrained shadows, modest corner radii, and subtle progress animation.
- Realistic Indonesian student portraits generated for profiles and peer matches.
- No course-store patterns, prices, childish illustrations, loud gamification, or generic AI gradients.

## Technical details
- Implement the screen in the existing TanStack React app using semantic Tailwind design tokens.
- Keep this first version frontend-only with realistic pilot data; no login, persistence, or live credit transfers yet.
- Add route-specific metadata for EXCHANGE and load the selected fonts correctly.
- Use reusable controls and data-driven sections so later Cloud-backed workflows can replace demo content cleanly.
- Verify the finished workspace at desktop and mobile sizes, including all key interactions and accessibility states.
